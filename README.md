# 抖音无水印下载器

粘贴一段抖音分享链接（带表情、话题的整段文案也可以），程序在本机解析出封面、标题、作者与**无水印视频直链**，一键下载无水印 mp4；图文作品可保存图集。全部计算在你自己的电脑上完成，无广告、不联网上报任何数据。

## 两个版本

| 版本 | 发行包 | 适合人群 | 运行方式 |
| --- | --- | --- | --- |
| Python 源码版 | `抖音无水印下载器-Python源码版.zip` | 想看源码、改界面改逻辑的人 | 需 Python 3.9+，双击 `启动.bat` 自动安装依赖并启动 |
| Java 便携版 | `抖音无水印下载器-Java便携版.zip` | 不想装环境、双击即用 | 解压后双击 `启动.bat`，包内自带 JRE，无需另外安装 Java |

> 发行包（含编译产物与 Java 自带运行环境）以附件 / Release 形式随仓库提供；仓库内文本为项目说明与源码。

## 功能特点

- 粘贴整段分享文案即可解析，自动提取其中的视频链接
- 输出封面、标题、作者和无水印 mp4 直链，下载支持 Range 断点续传
- 多数情况下免登录直接解析；解析失败或需要查看更多作品时，可在网页右上角扫码登录，登录态仅保存在本机
- 本地网页界面，默认地址 `http://127.0.0.1:3000`，同一 WiFi 下的手机或其他电脑也可访问
- 由真实浏览器内核（Edge / Chrome）带着本机登录态去请求数据；网页播放器拿到的流本身不含水印层，因此不需要后期再做去水印处理

## Python 源码版文件说明

- `app.py`：主程序，HTTP 服务 + 内嵌网页界面 + 接口路由
- `dyengine.py`：解析引擎，用 Playwright 驱动 Edge / Chrome 抓取抖音数据
- `engine_cli.py`：命令行调试版，可以脱离网页单独测试解析
- `requirements.txt`：依赖清单，第三方库仅 playwright 一个
- `启动.bat`：双击自动检查依赖并启动

常用命令：

```bash
python engine_cli.py --check              # 查看登录状态
python engine_cli.py --login              # 打开窗口扫码登录
python engine_cli.py --resolve <分享文本>  # 直接输出视频直链
```

## Java 便携版文件说明

- `DouyinNoWM.jar`：程序本体，纯 JDK 8、零第三方依赖（JSON 解析、WebSocket 客户端均为手写）
- `jre/`：自带的 Java 运行环境，请勿删除或改动
- `web/index.html`：网页界面，修改后重启即生效
- `启动.bat`：双击启动脚本

## 使用步骤（Java 便携版）

1. 把压缩包解压到任意目录（不要在压缩包内直接运行，也不要只单独拖出其中文件）
2. 双击目录里的 `启动.bat`，等待几秒后浏览器自动打开 `http://127.0.0.1:3000`；黑色命令行窗口不要关闭
3. 在手机抖音里点「分享 → 复制链接」，把整段文字原样粘进网页输入框，点「解析」
4. 出现封面、标题、作者后点下载，得到无水印 mp4
5. 若提示需要登录，点网页右上角「登录抖音」，用手机抖音扫码确认即可

## 环境要求

- Windows 10 / 11，64 位；电脑装有 Edge 或 Chrome（Win10/11 自带 Edge 即可）
- Python 源码版需自行安装 Python 3.9 以上；Java 便携版无需安装 Java

## 已知限制

- 解析时会弹出一个浏览器窗口用于真实请求数据，属于正常现象，不要关闭
- 抖音登录态会过期（几天到几周），过期后重新扫码；登录态加密绑定当前用户与机器，不能跨机器迁移
- 不要高频连续解析，以免触发抖音风控；正常一天解析几十个没有问题
- 手机 4G 外网访问需要额外的内网穿透或公网服务器部署，不属于程序本身的能力
